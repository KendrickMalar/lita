プライバシーポリシー

最終更新: 2026-09-22 ／ 運営: muumoo（連絡先: kuno@muumoo.online）

Lita は、あなたの文章から書き方のプロファイル（Voice）を作り、投稿の下書きを書くデスクトップアプリです。このページでは、Lita が扱うデータと、その保存先・送信先・削除方法を説明します。

1. 扱うデータ

データ内容目的
アカウント情報Google アカウントのメールアドレスと、認証基盤（Supabase）が発行する利用者 IDサインインと、あなたのデータをあなただけに紐づけるため
取り込んだ文章note・Medium の公開記事、X の公式アーカイブ、貼り付けた文章、選んだテキストファイルVoice を作るため
Voice文章から抽出した書き方のプロファイル（言語、丁寧さ、トーン、文末、特徴語、引用 など）下書きを書くため
ブリーフと下書きあなたが書いたブリーフ、生成された下書き、採用／破棄の状態、生成時に送ったプロンプト下書きを書き、あとから見返せるようにするため

Lita は、利用状況の解析（アナリティクス）や広告のためのデータを収集しません。クラッシュレポートも送信しません。

2. 保存先

  • 上記のデータは、Supabase（データベースは東京リージョン）上の、Lita のアカウントに紐づく領域に保存されます。データベースの行はあなたの利用者 ID で保護され、他の利用者からは読めません。
  • サインインのセッション情報は、あなたの PC の OS キーチェーンに保存されます。
  • 「考える量」などの設定は、あなたの PC の中だけに保存されます。

3. 送信先

  • OpenAI（Codex CLI 経由）。 Voice を作るときに取り込んだ文章を、下書きを書くときにブリーフと Voice の構造化プロファイルを、あなたの PC にインストールされた Codex CLI を通じて OpenAI に送ります。Lita は Codex の認証情報に触れません。送る内容は生成の前にアプリ内でそのまま確認できます。OpenAI 側の取り扱いは OpenAI の規約に従います。
  • Google。 サインインに Google OAuth を使います。Lita が受け取るのはメールアドレスと基本的なプロフィール（openid / email / profile）だけで、Gmail やドライブなどにはアクセスしません。
  • note・Medium。 取り込みのとき、あなたが指定したアカウントの公開記事を、それぞれの公開 API または RSS から取得します。

これ以外の第三者にデータを提供・販売することはありません。

4. 削除

  • Voice はアプリ内の「作り直す」で削除でき、紐づく取り込み文章・ブリーフ・下書きも一緒に削除されます。
  • アカウントごとすべてのデータを削除したい場合は、kuno@muumoo.online に連絡してください。確認のうえ削除します。

5. オープンソース

Lita のソースコードは MIT ライセンスで GitHub に公開されています。データの流れはコードで確認できます。自分で Supabase プロジェクトを立てて運用する（セルフホスト）こともできます。その場合、保存先はあなたのプロジェクトになります。

6. 変更

このポリシーを変更するときは、このページを更新し、冒頭の日付を改めます。
