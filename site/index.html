あなたの文体で、あなたの投稿を。

Lita は、あなたが書いた文章から「Voice」を作り、一行のブリーフから投稿の下書きを書くデスクトップアプリです。あなたは読んで、直して、採用するだけです。

GitHub で見る プライバシーポリシー

どう動くか

  • Voice を作る。 note や Medium の公開記事、X のアーカイブ、あるいは貼り付けた文章から、書き方のプロファイルを 1 つ作ります。
  • ブリーフを書く。 何について、誰に向けて、何を持ち帰ってほしいか。1〜2 文で十分です。
  • 下書きを判断する。 Lita が Voice どおりに書いた下書きを、直してコピーします。投稿は自分で行います。

Codex のログインをそのまま使う

Lita は API キーを求めません。手元にインストール済みの OpenAI Codex CLI を起動するだけで、認証情報には触れません。Codex に送る内容は、生成の前にそのまま確認できます。

インストール

Apple Silicon の Mac（macOS 12 以降）向けです。最新のリリースから DMG をダウンロードしてください。

まだ Apple の署名を付けていないため、初回は macOS が開くのを拒みます。「システム設定 › プライバシーとセキュリティ › このまま開く」を押すか、ターミナルで次を実行してください。

xattr -d com.apple.quarantine /Applications/Lita.app

入れたあとは、起動時とメニューの「Lita › アップデートを確認…」から更新できます。
